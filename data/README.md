# Version 1 catalog

The static demo uses three files:

- `printers.json` stores the printer models and normalized search values.
- `toners.json` stores cartridge specifications.
- `compatibility.json` maps each printer to the toner IDs that fit it.

The starter catalog contains 40 Brother printer models across these families:

- TN730 / TN760
- TN830 / TN830XL
- TN630 / TN660
- TN820 / TN850
- TN229 standard and high-yield colour cartridges

Compatibility and yield data were cross-checked against Brother's North American product information. Before expanding this into a production service, revalidate records against the official regional Brother product pages because model availability can differ by country.
